# Ambience Audio

Place optional environment loops here as `.ogg` files. The game looks for these names and falls back to generated placeholder beeps if a file is missing:

- `atm-left.ogg`
- `teller-terminal-a.ogg`
- `teller-terminal-b.ogg`
- `printer-room.ogg`
- `coin-sorter.ogg`
- `server-rack.ogg`
- `camera-console.ogg`
- `backup-generator.ogg`
- `archive-safe.ogg`
- `alarm-panel.ogg`

Use short mono or stereo loops where possible. CC0 sources are preferred.
